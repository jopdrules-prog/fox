# FOX Center 자동 업데이트

FOX Center 0.3.0 이상에 연결하는 공식 서명 패치 배포 폴더입니다.

## 처음 한 번 연결

메인 데스크탑의 FOX Center에서 **자동 업데이트**를 여세요.

1. **온라인 패치 주소**에 아래 주소를 붙여 넣습니다.
2. **새 패치 자동 설치**를 켜고 **저장**을 누릅니다.
3. **지금 확인**을 누릅니다.

```text
https://raw.githubusercontent.com/jopdrules-prog/fox/main/fox-center/latest.json
```

연결 후 센터가 실행 중이고 인터넷에 연결되어 있으면 약 15분마다 새 패치를 확인합니다.
착용샷 작업·실제 상품명/특징 작성·수동 초안 대기 또는 OBS 화면이 연결되어 있으면 자동 재시작을 미룹니다.
시작 전 자동 상품명 대기는 그대로 보존해 패치 후 이어서 처리합니다.
방송이 끝난 뒤 필요하면 **지금 적용 · 재시작**을 누르세요.
이미 0.3.28이면 최신 버전이라는 안내가 나오며, 이후 더 높은 버전이 게시되면 받습니다.
연결된 휴대폰과 노트북에 별도 패치를 설치할 필요는 없습니다.

## 현재 배포: 0.3.28

- 바탕화면에서 찾기 쉽게 **초록 바탕 + 큰 흰색 FOX + 금색 ▶** 시작 아이콘을 적용합니다.
- 작은 아이콘부터 큰 아이콘까지 16·24·32·48·64·128·256픽셀을 포함합니다.
- 자동패치가 정상 적용된 뒤 메인 Windows PC의 기존 FOX Center 바로가기 아이콘을 갱신합니다. 기존 이름과 실행 대상은 유지합니다.
- 일치하는 센터 바로가기가 없으면 **FOX 시작**을 만듭니다. 다른 프로그램의 바로가기는 덮어쓰지 않습니다.
- 아이콘은 센터 보관 폴더에 유지되어 다운로드 폴더를 옮겨도 함께 사라지지 않습니다. 별도 아이콘 설치는 필요하지 않습니다.
- 바탕화면 접근이 막혀 실패하면 센터 실행은 계속하고 다음 시작 때 다시 시도합니다. 기존 센터 바로가기에서 실행하면 됩니다.
- 0.3.27 화보 연출과 0.3.26 날짜별 번호, 사진·상품명·가격·재고·발주·OBS 기능을 유지합니다.
- 실제 사용자 PC의 설치 완료와 Windows 바탕화면 표시는 이 환경에서 직접 확인하지 못했습니다.

- 실제 생성 결과는 원본과 비교해 확인하세요. 같은 지침도 매번 다른 결과가 나오며, 사용자 PC의 이미지 생성 결과와 실제 설치는 아직 확인하지 않았습니다.

- 일·월 합쳐 100개를 넘더라도 날짜별로 100개 이하이면 각각 모두 번호를 매깁니다. 한 날짜 자체가 100개를 넘으면 모든 사진을 유지하고 미지정 개수를 안내합니다.
- 같은 상품을 양일에 넣으면 상품명·가격·재고는 공유하고 방송번호만 날짜별로 관리합니다. 손님 안내 전에 날짜와 번호를 확인하세요.
- 다른 날짜의 번호, 상품명·가격·재고·거래처·기존 발주 기록·현재 OBS 화면을 보존합니다. 새 번호는 방송에 적용할 때 반영합니다.
- 네 명의 동시 편집, 오래된 요청 거절, 번호 복구 실패 원복과 재시작 후 수동 수정 보존을 검증했습니다.
- 같은 디자인 이름 통일·색상 표시와 캡처 검색은 유지합니다. 유료 API나 별도 재설치를 추가하지 않습니다.
- 아래 0.3.25의 일·월 통합 안내는 이전 버전 기록입니다. 현재는 날짜별 분리 방식입니다.
