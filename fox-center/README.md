# FOX Center 자동 업데이트

FOX Center 0.3.0 이상에 연결하는 공식 서명 패치 배포 폴더입니다.

## 처음 한 번 연결

메인 데스크탑의 FOX Center에서 **자동 업데이트**를 여세요.

1. **온라인 패치 주소**에 아래 주소를 붙여 넣습니다.
2. **새 패치 자동 설치**를 켜고 **저장**을 누릅니다.
3. **지금 확인**을 누릅니다.

```text
https://raw.githubusercontent.com/jopdrules-prog/fox/main/fox-center/latest.json
```

연결 후 센터가 실행 중이고 인터넷에 연결되어 있으면 약 15분마다 새 패치를 확인합니다.
착용샷·옷 특징 생성 또는 대기 작업이 있거나 OBS 화면이 연결되어 있으면 자동 재시작을 미룹니다.
방송이 끝난 뒤 필요하면 **지금 적용 · 재시작**을 누르세요.
이미 0.3.13이면 최신 버전이라는 안내가 나오며, 이후 더 높은 버전이 게시되면 받습니다.
연결된 휴대폰과 노트북에 별도 패치를 설치할 필요는 없습니다.

## 현재 배포: 0.3.13

- **사진 작업실 → ＋ 직접 만든 착용샷 추가**에서 다른 곳에서 만든 완성 사진을 보관합니다.
- 새 상품은 선택한 방송 날짜의 빈 **1~100번**을 즉시 배정하고, 올린 사진을 보고 상품명을 작성합니다.
- **등록할 곳**에서 기존 상품을 선택하면 이름·가격·수량·원본·기존 방송번호를 유지하며 착용샷만 연결합니다. 이전 결과는 이력에 남습니다.
- PC 사진 끌어놓기·사진 영역에서 Ctrl+V·휴대폰 파일 선택을 지원합니다. 선택 후 추가 버튼을 눌러야 보관합니다.
- 새 상품은 여러 장씩 추가할 수 있고 실패한 사진은 재시도하도록 남겨 둡니다. 기존 상품 연결·상품명 직접 입력은 한 장씩 합니다.
- 여러 직원의 동시 번호 충돌과 같은 파일의 중복 상품 등록을 막습니다. 휴지통 사진은 확인 후 복원하고 기존 이름·번호를 유지합니다.
- 이름 작성은 기존 ChatGPT 연결·사용 한도를 사용합니다. 연결 전에도 사진 보관과 번호 배정은 되며 이름은 대기합니다. 이름을 직접 입력하면 자동 이름 요청을 생략합니다.
- 새 사진을 생성하거나 크기·해상도를 바꾸지 않습니다. 확인 후 방송에 적용해야 OBS에 표시됩니다.
- 이름과 번호는 상품을 열어 고칠 수 있습니다. 여러 옷이 보이는 사진은 판매할 상품과 이름을 확인하세요.

## 이전 배포: 0.3.12

- **원본 사진 / 착용샷**을 분리해서 보되 같은 옷은 한 상품, 같은 이름·가격·수량·방송번호로 관리합니다.
- 착용샷 목록은 현재 결과만 상품당 한 장씩 표시하며 이전 수정본은 해당 상품의 이력에서 봅니다.
- 상품 상세 맨 위에서 같은 이름의 원본·착용샷을 비교합니다. 다운로드도 같은 상품명 뒤에 원본/착용샷을 붙입니다.
- 착용샷 생성 시 상품명을 함께 작성하고, 이름만 빠지면 완성 이미지를 보관한 채 이름을 이어서 작성합니다.
- 이름 후속 작업은 상품당 한 번 자동 등록하며 기존 이름·초안·진행 작업은 보호합니다. 기존 ChatGPT 한도를 사용하고 실패 후 자동 반복하지 않습니다.
- 아름답고 품격 있는 실제 40대 중반 럭셔리 모델의 얼굴·표정·메이크업·조명 기준과 **얼굴 더 세련되게** 수정 버튼을 추가했습니다.
- **서기 → 앉기 → 기대기 → 걷기/움직임** 계열과 장소를 순환합니다. 옷 전체가 보이는 경우에만 앉으며 원피스·바지 등은 서 있는 대안을 사용합니다.
- 원본 의상·긴 웨이브·선글라스·4K 요청·기존 데이터와 방송 화면은 유지합니다. 실제 얼굴·포즈 품질은 다음 결과에서 확인해 주세요.

## 이전 배포: 0.3.11

- 새 착용샷을 만들 때 원본 옷의 특징과 종류로 짧고 세련된 한국어 상품명을 함께 요청하고 저장합니다.
- 예: 수채 플라워 가디건, 배색 트위드 재킷, 와이드 페인팅 데님. 확인되지 않은 소재·브랜드·등급은 넣지 않도록 지시합니다.
- 사진 상세의 상품명을 직접 고쳐 저장할 수 있습니다. 연결된 기기에서 같은 이름으로 검색·확인·복사합니다.
- 기존 사진은 **사진으로 상품명·특징 만들기**에서 제안을 받은 뒤 원하는 이름을 골라 저장할 수 있습니다.
- 이름과 특징 초안을 따로 선택하며, 기존 이름·가격·직접 쓴 설명은 재생성으로 덮어쓰지 않습니다.
- 동시 수정 충돌과 작성 중 입력을 보호합니다. 재시작·휴지통 복원·동일 원본 재추가에도 이름이 유지됩니다.
- 이름은 상품 정보로 저장하며 화보 위에 추가 문구로 넣지 않습니다. 실제 명칭은 실물과 확인하세요.
- 새 착용샷의 이름은 기존 생성 요청에 포함합니다. 별도 유료 API나 추가 자동 생성 요청은 없습니다.
- 이름 메모를 받지 못해도 완성된 착용샷은 보관하며 파일명을 유지합니다. 상품명을 직접 입력할 수 있습니다.

- 같은 센터에 연결된 PC·노트북·휴대폰은 별도 설치 없이 메인 버전 변경을 확인하고 새 화면을 자동으로 받습니다.
- 저장·사진 작업, 상품 창, 변경한 설정, 사진 선택·검색 중에는 새로고침을 미룹니다. 작성 내용을 저장하고 작업을 마쳐 주세요.
- 최근 입력을 마친 뒤 약 15초 쉬고 입력칸 밖에 있으면 다음 확인 때 자동 갱신합니다. 직접 받기에는 입력 폐기 확인을 제공합니다.
- 화면 복귀·포커스·온라인 이벤트에서 재확인하며, 연결이 잠시 끊겨도 입력을 유지합니다. 중복 조회를 합칩니다.
- 메인 센터와 이 기기 화면의 버전을 구분해 표시합니다. 입력 보호는 0.3.10 화면을 받은 이후 적용됩니다.
- OBS 연결·이미지 생성 중 서버 재시작 보호는 유지합니다. 별도 주문센터·카메라 도우미의 패치는 각 프로그램이 관리합니다.

휴지통은 번호를 유지하지만, 사진을 방송 날짜에서 빼거나 영구 삭제하면 해당 번호도 해제합니다.

## 이전 배포: 0.3.4

- 선호 화보 연출을 분석해 모델·헤어·메이크업·조명·포즈 지시를 구체화했습니다.
- 40대 중반 럭셔리 캠페인 모델, 풍성하고 윤기 있는 긴 웨이브, 여유로운 표정과 따뜻한 사선 자연광.
- 유럽 카페·꽃집·부티크 배경, 선택적인 선글라스·작은 골드 주얼리와 조화로운 보조 코디.
- 옷의 색상·핏·길이와 디테일을 보존하고, OBS에서도 옷과 발끝이 보이는 전신 9:16을 요청합니다.
- 걷기·기대기 등 포즈를 다양화하고 앉은 자세는 상의 전체가 가려지지 않을 때만 허용합니다.
- **선호 화보 스타일 → 수정본 만들기**로 기존 옷을 유지하며 모델·포즈·배경·조명을 새로 연출할 수 있습니다.
- 모델 변경·포즈 변경 등 부분 수정과 이전 결과 복원도 유지합니다.
- 참고 이미지 자체를 배포하거나 매번 첨부하지 않습니다. 공통 연출을 텍스트 지시로 반영합니다.
- 기존 사진은 자동 재생성하지 않습니다. 휴지통·가격·날짜·방송 확인 기능은 유지됩니다.

## 이전 배포: 0.3.3

- **사진 작업실 → 휴지통 → 휴지통 전체 비우기**를 추가했습니다.
- 모든 방송분의 휴지통 전체 장수와 복구 불가 안내를 확인한 뒤 영구 삭제합니다.
- 휴지통 사진을 다시 업로드하거나 기존 화보에서 가져오면 복원해서 추가할지 묻습니다.
  확인하면 원본·완성본·수정 이력을 복원하고 선택한 방송 날짜에 추가합니다.
- 다른 직원이 휴지통을 바꾸면 오래된 삭제 확인을 거부합니다. 생성·방송 중인 사진도 보호합니다.
- 잠긴 파일은 정리를 이어가며, 다른 사진이 사용하는 파일과 가격 원장은 보존합니다.
- 삭제는 센터 보관함에만 적용됩니다. 별도 백업·생성 작업 기록·기존 FOX 원본은 지우지 않습니다.
- 패치를 설치하는 것만으로 휴지통이 비워지지는 않습니다.

## 이전 배포: 0.3.2

- 요청한 영문 화보 프롬프트를 적용하고 모델 나이를 **실제로 40대 중반(45세 전후)**으로 강화했습니다.
- 명품 패션 매거진·럭셔리 캠페인 수준의 모델, 표정, 조명, 포즈와 스타일링을 지시합니다.
- 새 착용샷 생성과 완성본 수정, 모델 변경 버튼에 같은 기준을 적용합니다.
- 긴 웨이브, 원본 옷의 색상·핏·디테일, 상단 LUMIÈRE FOX, 유럽 거리 전신 9:16,
  새 사진마다 모델·포즈·장소 변경, 베스트 이너 규칙을 유지합니다.
- 기존 사진은 자동으로 다시 생성하지 않습니다. 사진을 열고 수정 요청하면 새 기준을 적용합니다.
- 4K는 목표이며 실제 해상도는 이미지 생성 도구의 지원 범위에 따릅니다.
