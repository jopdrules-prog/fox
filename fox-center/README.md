# FOX Center 자동 업데이트

FOX Center 0.3.0 이상에 연결하는 공식 서명 패치 배포 폴더입니다.

## 처음 한 번 연결

메인 데스크탑의 FOX Center에서 **자동 업데이트**를 여세요.

1. **온라인 패치 주소**에 아래 주소를 붙여 넣습니다.
2. **새 패치 자동 설치**를 켜고 **저장**을 누릅니다.
3. **지금 확인**을 누릅니다.

```text
https://raw.githubusercontent.com/jopdrules-prog/fox/main/fox-center/latest.json
```

연결 후 센터가 실행 중이고 인터넷에 연결되어 있으면 약 15분마다 새 패치를 확인합니다.
생성 작업 중이거나 OBS 화면이 연결되어 있으면 자동 재시작을 미룹니다.
방송이 끝난 뒤 필요하면 **지금 적용 · 재시작**을 누르세요.
이미 0.3.3이면 최신 버전이라는 안내가 나오며, 이후 더 높은 버전이 게시되면 받습니다.
연결된 휴대폰과 노트북에 별도 패치를 설치할 필요는 없습니다.

## 현재 배포: 0.3.3

- **사진 작업실 → 휴지통 → 휴지통 전체 비우기**를 추가했습니다.
- 모든 방송분의 휴지통 전체 장수와 복구 불가 안내를 확인한 뒤 영구 삭제합니다.
- 휴지통 사진을 다시 업로드하거나 기존 화보에서 가져오면 복원해서 추가할지 묻습니다.
  확인하면 원본·완성본·수정 이력을 복원하고 선택한 방송 날짜에 추가합니다.
- 다른 직원이 휴지통을 바꾸면 오래된 삭제 확인을 거부합니다. 생성·방송 중인 사진도 보호합니다.
- 잠긴 파일은 정리를 이어가며, 다른 사진이 사용하는 파일과 가격 원장은 보존합니다.
- 삭제는 센터 보관함에만 적용됩니다. 별도 백업·생성 작업 기록·기존 FOX 원본은 지우지 않습니다.
- 패치를 설치하는 것만으로 휴지통이 비워지지는 않습니다.

## 이전 배포: 0.3.2

- 요청한 영문 화보 프롬프트를 적용하고 모델 나이를 **실제로 40대 중반(45세 전후)**으로 강화했습니다.
- 명품 패션 매거진·럭셔리 캠페인 수준의 모델, 표정, 조명, 포즈와 스타일링을 지시합니다.
- 새 착용샷 생성과 완성본 수정, 모델 변경 버튼에 같은 기준을 적용합니다.
- 긴 웨이브, 원본 옷의 색상·핏·디테일, 상단 LUMIÈRE FOX, 유럽 거리 전신 9:16,
  새 사진마다 모델·포즈·장소 변경, 베스트 이너 규칙을 유지합니다.
- 기존 사진은 자동으로 다시 생성하지 않습니다. 사진을 열고 수정 요청하면 새 기준을 적용합니다.
- 4K는 목표이며 실제 해상도는 이미지 생성 도구의 지원 범위에 따릅니다.

## 이전 배포: 0.3.1

- 설치 중단 후 복구와 업데이트 재시작 처리를 개선했습니다.
- 온라인 확인에 실패해도 내려받은 서명 패치를 계속 확인합니다.
- 여러 직원이 사진을 처리할 때 방송 날짜, 결과 이력, 승인 대상을 더 정확하게 확인합니다.
- 설치된 공개키로 패치 서명과 파일 해시를 검증하고 적용 전 데이터베이스를 백업합니다.

이 폴더에는 공용 프로그램 패치와 서명된 업데이트 목록만 게시합니다.
사용자 사진, 가격 기록, 로그인 정보와 서명용 비밀키는 포함하지 않습니다.
앱 데이터는 메인 데스크탑에 보관됩니다.

실제 Windows 데스크탑에서의 적용 여부는 센터에 표시되는 버전과 상태로 확인하세요.
