FOX 카메라 도우미 1.1.0 · 자동 업데이트

처음 한 번: 메인 데스크탑에서 FOX_Camera_Auto_Update_Setup.cmd 실행.
자동 업데이트 파일을 설치하고 바탕 화면에 FOX 카메라 도우미 아이콘을 만듭니다.
현재 카메라 도우미가 켜져 있으면 종료하지 않습니다.
방송이 끝난 뒤 기존 FOX Camera Assist 창만 닫고 새 바탕 화면 아이콘으로 실행하세요.
기존 방송 도우미, FOX 센터, OBS Studio는 그대로 사용합니다.

앞으로 바탕 화면의 새 아이콘으로 실행하면 새 버전을 확인하고 자동 적용합니다.
사용 중에도 한 시간마다 새 버전을 확인하여 받아 둡니다. 실행 중에는 교체하지 않습니다.
인터넷이 끊기거나 검사가 실패하면 현재 설치된 버전으로 시작합니다.
새 버전의 시작 확인에 실패하면 이전 버전과 백업한 카메라 설정으로 돌아갑니다.
문제가 난 버전은 다시 자동 설치하지 않습니다. 다음 수정 버전은 받을 수 있습니다.
프로그램 화면 위에서 자동 업데이트 상태를 확인할 수 있습니다.

카메라 설정·방향·영역·기억시킨 옷·인식 모델은 기존 LocalAppData 경로를 유지합니다.
상품 사진·가격·설명은 기존 FOX 프로그램에서 사용하며 이 설치기는 변경하지 않습니다.
OBS 비밀번호는 기존대로 메모리에만 보관하므로 도우미를 다시 켜면 입력해야 합니다.
OBS 노트북에서는 기존 8772 카메라 방을 새로고침하여 조작합니다.
재시작 후 연결번호를 물으면 데스크탑의 새 연결번호를 입력합니다.
착용샷 전환은 계속 사용자가 맞는 사진을 눌렀을 때만 실행합니다.

GitHub 연결과 자동 업데이트 설치는 다릅니다.
연결만으로 PC에 설치되지 않으며 최초 설정 파일은 PC에서 한 번 실행해야 합니다.
자동 업데이트는 GitHub에 실제로 배포된 카메라 도우미 버전을 받는 기능입니다.
프로그램이 스스로 코드를 만들거나 OBS Studio 자체를 업데이트하는 기능은 아닙니다.
OBS Studio를 종료하거나 방송을 다시 시작하지 않습니다.

FOX 카메라 도우미 1.0.5 · OBS 노트북에서 상품 준비와 사진 전환

카메라에서 옷을 찾고 → 후보 사진을 크게 보여주고 → 내가 동의하면 착용샷 전환
동의하지 않으면 현재 방송 사진을 유지합니다.

1.0.5 노트북에서 계속 조작하기
이번 교체만 메인 데스크탑에서 합니다.
1. FOX Camera Assist 검은 창만 닫습니다.
2. 이 ZIP을 새 폴더에 모두 압축 풀고 START_CAMERA.cmd를 실행합니다.
3. 화면 위 버전 1.0.5를 확인합니다.
4. OBS 비밀번호 입력 → 설정 저장 → 카메라 연결 확인.
   기존 주소·소스 이름·방향·옷 영역·기억시킨 옷·인식 모델은 유지됩니다.
5. OBS 노트북에서 기존 카메라 방 주소를 새로고침합니다.
   연결번호를 물으면 데스크탑 화면 맨 아래에 표시된 새 번호를 입력합니다.
6. 이제 노트북 화면 맨 위 ‘상품 준비’ → 준비 완료 후 ‘자동 찾기 시작’을 누릅니다.
7. 후보가 맞으면 노트북에서 ‘이 사진으로 바꾸기’를 누릅니다.
   옷을 기억시킨 뒤에도 같은 노트북의 ‘상품 준비’ → ‘자동 찾기 시작’을 누릅니다.

메인 데스크탑에서는 기존 방송 도우미와 카메라 도우미를 계속 켜 둡니다.
노트북에는 이 ZIP을 설치하지 않습니다. 인터넷 브라우저로 연결해서 조작합니다.
처음 카메라 연결·비밀번호·회전·옷 영역 설정은 메인 데스크탑에서 합니다.
OBS에는 기존 화보 전용 화면 주소를 계속 사용합니다.
상품 준비·찾기·기억하기만으로 방송 사진이 바뀌지는 않습니다.

1.0.4 사진 읽기 호환성과 빈 오류 표시 보완
1. FOX Camera Assist 검은 창만 닫습니다.
2. 이 ZIP을 새 폴더에 모두 압축 풀고 START_CAMERA.cmd를 실행합니다.
3. 화면 위와 아래의 버전 1.0.4를 확인합니다.
4. OBS 비밀번호 입력 → 설정 저장 → 카메라 연결 확인.
5. 사진이 나오면 회전 버튼으로 방향을 맞춥니다.
6. 실패하면 이제 빨간 칸에 표시되는 오류 문구를 보여주세요.

OBS가 지원한다고 알린 형식 중 JPG를 먼저 요청합니다. JPG가 실패하고 PNG가 지원되면 PNG를 한 번 더 시도합니다.
소스 이름이 틀리거나 카메라가 숨겨졌으면 그 원인을 표시합니다.
실패 단계와 오류 종류를 표시하므로, 오류에 설명이 없어도 빨간 칸이 빈칸이 되지 않습니다.
OBS 설정과 방송 화면은 변경하지 않습니다. 실제 사용자 카메라에서 해결됐는지는 다시 연결해서 확인해야 합니다.

1.0.3 옆으로 누운 카메라 방향 수정
1. 기존 FOX Camera Assist 검은 창만 닫습니다.
2. 이 ZIP을 새 폴더에 모두 압축 풀고 START_CAMERA.cmd를 실행합니다.
3. 화면 맨 아래 버전 1.0.3을 확인합니다.
4. OBS 비밀번호를 입력 → 설정 저장 → 카메라 연결 확인.
5. 미리보기 위의 ‘오른쪽 90°’ 또는 ‘왼쪽 90°’로 옷을 똑바로 맞춥니다.
   방향은 바로 저장되며 프로그램을 다시 켜도 유지됩니다.
6. 노란 영역을 옷 한 벌에 맞춰 드래그 → 이 영역으로 설정 저장.
7. 상품 준비가 끝나 있으면 ‘자동 찾기 시작’을 누릅니다.
방향을 바꾸면 찾기가 잠시 멈춥니다. 영역 확인 후 다시 시작해 주세요.
미리보기·실제 인식·승인 때 재확인에 같은 방향이 적용됩니다.
OBS의 방송 화면 회전이나 소스 설정은 변경하지 않습니다.
기존 설정·사진·모델은 계속 사용합니다. 비밀번호만 다시 입력해야 합니다.
이 ZIP은 방송 도우미의 업데이트 버튼에 넣는 파일이 아닙니다.

1.0.2 카메라 연결 확인 개선본
사진 형식을 PNG로 요청합니다. 기존의 포괄적인 오류 문구만으로 정확한 원인은 알 수 없으므로,
실패한 OBS 요청 이름·오류 번호·사유를 표시하고, 실제 소스 목록도 함께 제공합니다.
1. FOX Camera Assist라고 적힌 이전 카메라 도우미의 검은 창을 닫습니다.
2. 이 ZIP을 새 폴더에 모두 압축 풀고 그 안의 START_CAMERA.cmd를 실행합니다.
3. 화면 아래 버전 1.0.2를 확인합니다. 노트북 주소와 설정은 유지됩니다.
4. OBS 비밀번호를 다시 입력 → 설정 저장 → 카메라 연결 확인.
5. 실패하면 아래 실제 소스 목록에서 카메라를 선택 → 설정 저장 → 카메라 연결 확인.
6. 여전히 실패하면 카메라 확인 결과의 오류 문구를 보여주세요.
기존 방송 도우미와 OBS는 계속 켜 둡니다.

1.0.1 실행 오류 수정 내용
윈도우에서 포트 설정이 충돌하는 부분을 수정했습니다.
이전에 도구 설치가 완료됐다면 같은 컴퓨터에서 다시 설치하지 않고 재사용합니다.
이 ZIP을 새 폴더에 모두 압축 풀고, 그 안의 START_CAMERA.cmd를 실행하세요.
실행 도중 오류가 나면 상세 오류 내용이 검은 창에 표시됩니다.

어느 컴퓨터에서 실행하나요?
기존 FOX 방송 도우미가 켜져 있는 메인 데스크탑에서 실행합니다.
OBS 노트북에는 이 프로그램을 설치하지 않아도 됩니다.
기존 프로그램의 업데이트 파일 선택 버튼에 이 ZIP을 넣지 마세요.

처음 실행
1. ZIP을 우클릭 → 모두 압축 풀기.
2. FOX_Camera_Assist 폴더 안의 START_CAMERA.cmd를 더블클릭.
   처음에는 무료 실행 도구를 준비하며 인터넷이 필요합니다.
3. 기존 FOX 방송 도우미도 켜 둡니다.
   현재 복구 폴더의 START_FOX.cmd로 실행하는 상태라면 그 방식을 유지하세요.
4. 카메라 도우미 화면이 열립니다. http://127.0.0.1:8772

OBS 노트북에서 한 번 설정
1. OBS → 도구 → WebSocket 서버 설정.
2. 서버를 활성화하고 인증을 켠 상태로 둡니다.
3. 서버 연결 정보에 표시된 노트북 IPv4 주소·포트·비밀번호를 확인합니다.
   이 비밀번호는 채팅에 보내지 말고 카메라 도우미 입력칸에 넣으세요.
4. 메인 데스크탑의 카메라 도우미에서 ‘처음 한 번 · 카메라 연결과 인식 준비’를 엽니다.
5. 노트북 주소·포트·비밀번호와 실제 카메라 소스 이름을 입력합니다.
   현재 확인한 카메라 이름은 DroidCamOBS입니다. 이름이 다르면 현재 OBS 이름을 사용하세요.
6. 설정 저장 → 카메라 연결 확인.
7. 미리보기에서 옷을 보여줄 부분만 드래그 → 이 영역으로 설정 저장.
   계좌 배너나 착용샷을 분석하는 일이 없도록, 카메라 소스만 선택하세요.
8. ‘인식 도구·상품 준비’를 누릅니다. 최초에는 약 89 MB 모델을 받습니다.
9. 준비가 끝나면 ‘자동 찾기 시작’.

방송 중
- 카메라의 옷을 4초 간격으로 봅니다. 같은 후보가 3번 안정적으로 잡히면 확인창이 뜹니다.
- 최대 세 장의 후보 중 맞는 사진 아래 ‘이 사진으로 바꾸기’를 누릅니다.
- ‘그대로 두기’를 누르거나 아무것도 누르지 않으면 사진을 바꾸지 않습니다.
- 옷이 바뀌거나 카메라 연결이 끊기거나 20초가 지나면 후보를 취소합니다.
- 승인 시 카메라를 한 번 더 확인합니다. 해당 요청은 한 번만 사용됩니다.
- ‘잠깐 멈추기’로 찾기를 멈출 수 있습니다.
- ‘방금 전 착용샷으로 돌리기’는 내가 눌렀을 때만 작동합니다.

OBS 노트북이나 휴대폰에서 동의하고 싶을 때
카메라 도우미 아래 ‘OBS 노트북·휴대폰에서 동의 버튼 누르기’를 엽니다.
같은 공유기의 해당 기기에서 표시된 주소와 연결번호를 사용합니다.
카메라 도우미 연결번호는 기존 방송 도우미의 연결번호와 별개입니다.
프로그램을 다시 켜면 연결번호와 세션이 새로 만들어집니다.

OBS에 어떤 주소를 넣나요?
기존 방송 도우미의 ‘기기 연결 → 화보 전용 화면’ 주소를 그대로 사용합니다.
이 카메라 도우미 주소(8772)를 OBS 브라우저 소스에 넣지 마세요.
이 프로그램은 진행자가 후보를 확인하는 화면입니다.
OBS의 오른쪽 착용샷 위치·크기, 카메라, 계좌 배너, 방송 시작/종료는 조작하지 않습니다.
기존 OBS 브라우저 소스가 정상 연결되어 있어야 선택한 사진이 송출 화면에 반영됩니다.

잘 찾지 못하는 옷
화보는 모델·장소·조명이 달라 실제 옷과 다르게 보일 수 있습니다.
검정 옷, 비슷한 무늬, 여러 벌이 겹친 옷은 혼동할 수 있습니다.
한 벌씩 정면으로 영역 안에 보여주세요.
‘착용샷과 연결해 기억시키기’에서 사진을 고르고, 해당 실제 옷을 카메라에 보여준 채
‘맞아요 · 이 옷 기억하기’를 누릅니다. 그다음 상품 준비를 다시 누릅니다.
방송 사진은 바뀌지 않으며, 인식용 숫자 특징만 이 보조 프로그램에 저장합니다.

비용·저장
유료 API나 API 키를 사용하지 않습니다. 설치 때 인터넷 다운로드가 필요합니다.
카메라 사진은 메인 데스크탑 메모리에서 처리하며 외부 서비스로 전송하지 않습니다.
카메라를 계속 녹화하거나 사진을 모아서 저장하지 않습니다.
실행 도구, 모델, 특징 캐시, 설정은 Windows LocalAppData의 FOX_Camera_Assist에 저장합니다.
OBS 비밀번호는 파일에 저장하지 않습니다. 프로그램을 다시 켜면 다시 입력해야 합니다.
기존 FOX 프로그램·복구 도구·사진·상품 파일을 직접 덮어쓰지 않습니다.
승인할 때만 기존 방송 도우미의 상품 선택 기능에 요청합니다.

확인 상태
승인 절차·연결 끊김·오래된 후보 방지와 실제 도우미의 사진 전환은 개발 환경에서 확인했습니다.
이전 1.0.1 화면이 Windows에서 열린 것은 확인됐습니다. 1.0.2에서 실제 OBS 카메라 읽기와 실제 옷 인식 정확도는 현장 확인이 필요합니다.
방송 전에 여러 벌로 후보가 맞는지 먼저 확인해 주세요.
